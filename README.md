## About

This repository documents coursework developed during the Data Science specialization at Universidade Tecnologica Federal do Parana (UTFPR). It consolidates practical exercises, analytical projects, and supporting datasets used to study programming, databases, semantic web, big data, analytical methods, data mining, and machine learning. The overall objective is to demonstrate applied learning across the data science workflow, from data preparation and modeling to interpretation and reproducible documentation.

## Disciplines

1. Introduction to Programming for Data Science covers foundational Python programming, notebooks, and initial analytical workflows.
2. Database focuses on structured data, SQL-oriented exercises, geospatial analysis, and database-supported projects.
3. Semantic Web explores RDF, OWL, SPARQL, GraphDB, Ontotext Refine, and semantic data transformation.
4. Big Data introduces columnar formats, Apache Spark, and data pipeline practices for larger datasets.
5. Analytical Methods emphasizes statistical methods, R-based analysis, and network-oriented analytical exercises.
6. Data Mining covers web data collection, regression, classification, clustering, association rules, and text mining.
7. Machine Learning applies supervised learning workflows, model evaluation, and practical predictive modeling exercises.
8. Data Sets centralizes reusable datasets used across disciplines and assignments.

## Stack & Prerequisites

The repository uses Python 3.12.7 with Jupyter, pandas, NumPy, scikit-learn, SciPy, matplotlib, seaborn, statsmodels, Streamlit, spaCy, NLTK, transformers, Selenium, PyArrow, openpyxl, and related data science libraries; some disciplines also use R, Docker, Docker Compose, GraphDB, Ontotext Refine, and QGIS project assets. To set up the Python environment, create a virtual environment with Python 3.12 and install dependencies with `pip install -r requirements.txt`.

## How to Navigate

Each top-level discipline folder contains the notebooks, scripts, datasets, and reports associated with that course module. Exercise folders generally group classroom activities or assignments, while `Trabalho` folders usually contain final or practical work for a discipline. Shared or reusable datasets are kept in `data-sets`, while discipline-specific data remains close to the notebook or script that uses it. Visitors should start with the discipline that matches their interest, open the notebooks first, and then inspect adjacent datasets, scripts, or reports for supporting context.
